# lern

Beginner-friendly study kits. Each subject has its own folder; open its `README.md` first.

| Subject | Folder | What's inside |
|---|---|---|
| Computer Vision (5th semester) | [`computer-vision/`](computer-vision/) | Weeks 1–4 (images → CNNs → detection/segmentation → video → transformers → GANs), worked lab notebooks, question-bank answers, mid-term project starters |
| Deep Learning & Generative AI | [`deep-learning-genai/`](deep-learning-genai/) | History of DL, AI vs ML vs DL vs GenAI, the neuron, perceptron, activation functions, loss functions, how an MLP learns (backprop), weight initialization, normalization & regularization, text → tokens → vectors, optimizers & gradient clipping, Transformers & a MiniGPT, encoder-decoder models, plus two ANN case studies on real data, with runnable experiments |

Every folder has plain-language notes, code to experiment with (already run, outputs included), a cheat sheet, a printable study-guide PDF, and the original course files in `course-files/`.
