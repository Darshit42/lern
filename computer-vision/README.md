# Computer Vision (5th semester): study kit

Each part of the course has its own folder. Open the folder's `README.md` first.

| Folder | Covers | Code style | Printable guide |
|---|---|---|---|
| [`week-1/`](week-1/) | Days 1–6: images & colour, transformations, filtering & convolution, histograms & thresholding, morphology, contours + Week 1 Key Concepts + question bank answers | Python scripts (`code/`) | `week-1/Week1_Study_Guide.pdf` |
| [`week-2/`](week-2/) | Week 2 Key Concepts (Days 8–15): Harris/SIFT/ORB + panoramas, matching + logo detector, optical flow/KLT, kNN/SVM, Bag of Visual Words, Haar/HOG faces, pre-CNN foundations, CNN basics + **all 7 Week 2 labs worked through** | Notes + executed lab notebooks (`labs/`) | `week-2/Week2_Study_Guide.pdf` |
| [`week-2-3/`](week-2-3/) | Week 3 Key Concepts: CNN architectures (LeNet → EfficientNet), detection (R-CNN/YOLO/SSD), segmentation (FCN/U-Net/Mask R-CNN), RNN/LSTM for video, Vision Transformers + Week 2–3 question bank answers + **all 7 Week 3 labs worked through** | Notes + notebooks + executed lab notebooks (`labs/`) | `week-2-3/Week2-3_Study_Guide.pdf` |
| [`week-4-gans/`](week-4-gans/) | GAN Classes 1–4: generator/discriminator and minimax, training dynamics (Nash equilibrium, instability, mode collapse, fixes), DCGAN and conditional GAN | Notes + the 3 course notebooks rebuilt and run | `week-4-gans/Week4_GANs_Study_Guide.pdf` |
| [`project/`](project/) | Mid-term project: three complete starter notebooks (face-recognition security, licence-plate OCR violations, attendance system) + report template | Jupyter notebooks | `project/README.md` |

Every folder has a `course-files/` subfolder with the original course PDFs and notebooks, so each week's material stays together.
